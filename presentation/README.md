### 소개 영상 장

2장(표지 바로 뒤)은 최종 홍보 영상(D-025) `promo/out/v3/promo-16x9.mp4`(19.5초, 12.5MB)를 그대로 넣었고, 멈춘 그림은 그 마지막 장면 `promo/out/v3/keyvisual-16x9.png`입니다. 2안은 영상이 1536 × 864로 슬라이드 넓이의 64%를 차지합니다(전에는 1100 × 619, 33%). 웹 덱의 발표 화면에서는 영상을 누르면 소리와 함께 재생되고, 다 끝나면 처음부터 다시 돕니다.

덱에서 PPTX·PDF로 내려받으면 영상 장에는 멈춘 그림만 들어갑니다. PPTX 한 파일로 영상까지 나오게 하려면, 내려받은 PPTX를 `embed-video.ps1`로 고칩니다.

```bash
powershell -ExecutionPolicy Bypass -File presentation/embed-video.ps1 -In "<내려받은 파일>.pptx" -Out "presentation/v2/불량품 선별 발표 2안.pptx"
```

- 영상 장 그림을 같은 자리·크기의 MP4로 바꿉니다(링크가 아니라 파일 안에 넣음). 재생 전에는 영상 마지막 장면이 보입니다.
- 그 장에서 다음 키(클리커)를 한 번 누르면 소리와 함께 재생되고, 한 번 돈 뒤 마지막 장면에 멈춥니다. 영상을 누르면 멈췄다가 다시 재생됩니다.
- 글꼴(Noto Sans KR)을 파일 안에 넣어, 그 글꼴이 없는 PC에서도 같은 글꼴로 보입니다. 이 PC처럼 글꼴이 깔린 곳에서 돌려야 합니다.
- 내려받은 PPTX는 PowerPoint에서 한글 낱말이 중간에서 끊깁니다(문단에 `eaLnBrk`가 없고 글자 언어가 en-US). 그래서 모든 문단에 `eaLnBrk="0"`을 넣고 글자 언어를 ko-KR로 붙이며, 가운뎃점(·)은 앞말에 붙입니다.
- 낱말 단위로 바뀌어 넘치는 글 상자는 맞을 때까지 글자를 4%씩 줄이고, 폭과 글자 크기가 같은 나란한 상자도 같은 비율로 줄입니다. 2안은 5장 설명 네 개가 96%가 됐습니다.

완성본은 `v2/불량품 선별 발표 2안.pptx`(15장, 19.6MB — 내려받은 파일은 2.2MB)입니다. PowerPoint로 15장을 이미지로 뽑아 넘침·겹침이 없는 것을 보았습니다 (직접 2026-11-03). 덱을 고치면 PPTX를 다시 내려받아 위 명령을 다시 돌립니다.

### 조작 화면 사진

시험용 XML 서버(`.claude/launch.json`의 `xml-server-video`, 시뮬레이션)에 붙인 빌드 화면을 헤드리스 Edge로 1600 × 960, 2배로 찍었습니다. 원점을 미리 저장해 두고 시작 키와 카메라 연결을 누른 뒤 찍어서, 가동 중·자동 모드·불량품 선택 상태입니다.

- 통계 숫자는 시뮬레이션 값입니다(2초마다 1개, 5번째마다 불량).
- 카메라 칸은 시험 프레임 대신 그린 탑뷰 그림(컨베이어 위 부품 셋, 가운데 하나가 깨짐)으로 바꿔 보였습니다. 실제 카메라 영상이 아닙니다.

```bash
npm ci --prefix promo
```

```bash
node presentation/assets/shot.mjs . presentation/assets 30000
```

두 번째 명령은 `xml-server-video`(5092)가 떠 있을 때 돌립니다. 마지막 숫자는 시작 뒤 기다리는 밀리초입니다.

### 글꼴

1안 Gothic A1, 2안 Noto Sans KR, 3안 IBM Plex Sans KR + JetBrains Mono (모두 Google Fonts). 한글 글꼴은 PPTX에 들어가지 않아, 그 글꼴이 없는 PC의 PowerPoint에서는 다른 글꼴로 바뀝니다. 발표 PC에 글꼴을 깔거나 PDF로 내려받아 씁니다.
