# 불량 선별 HMI (웹)

불량품 감지 시스템의 조작 화면과 감시 화면입니다. 최종 형태는 웹으로 확정했습니다.
서버가 아직 없어 지금은 브라우저 안의 가짜 서버(`js/mock-server.js`)가 [API 초안 v0.2](../docs/API.md)대로 응답합니다.
실제 서버가 생기면 [서버 점검](tools/server-check.html)으로 형식을 확인한 뒤 `js/config.js`를 맞춥니다 — 사례별 설정은 [서버 형식 대응표](../docs/server-cases.md).
로봇팔 키트(SO-ARM101 기반)에 맞춘 값과 설치 순서는 [로봇팔 문서](../docs/robot-arm.md)에 있습니다.

## 실행

`index.html`을 더블클릭하면 바로 열립니다 (모듈 없이 일반 스크립트만 씁니다).
점검 도구·여러 창 공유까지 쓰려면 로컬 서버로 여세요. 개발용 서버는 파일을 캐시하지 않아 고친 뒤 새로고침하면 바로 반영됩니다.

```bash
python hmi-web-mockup/tools/dev-server.py 5173
```

| 주소 | 화면 |
|---|---|
| `http://localhost:5173/` | 조작 화면 (개발용 장치 연결 표시 포함) |
| `http://localhost:5173/dashboard.html` | 대시보드 (감시 값 + 조작) |
| `http://localhost:5173/dashboard-tabs.html` | 대시보드 탭 시안 — 조작 기능과 감시 값을 왼쪽 탭 9개로 나눈 두 번째 안 |
| `http://localhost:5173/tools/devices.html` | 장치 점검 — 로봇팔 서보·USB 카메라·아두이노 (설치·고장 확인용) |
| `http://localhost:5173/tools/server-check.html` | 서버 점검 — 서버 형식 확인과 `config.js` 제안 값 |

주소 뒤에 붙이는 설정 (설정 파일보다 우선, 화면 이동 버튼이 그대로 넘김)

| 붙이는 것 | 뜻 |
|---|---|
| `?dev=0` / `?dev=1` | 배포 화면 / 개발 화면 (장치 연결·흉내 버튼) |
| `?theme=light` · `dark` · `auto` | 테마 고정 |
| `?mock=0` | 가짜 서버 대신 실제 서버 |
| `?api=…&ws=…` | 서버 주소 (예: `?mock=0&api=http://192.168.0.10:8000/api&ws=ws://192.168.0.10:8000/ws`) |
| `?push=socketio` · `sse` · `poll` | 실시간 방식 |

가짜 서버는 조작 화면과 대시보드를 두 창에 띄워도 **하나를 나눠 씁니다** (`js/mock-hub.js`). 화면에 보이는 탭이 서버를 맡고,
그 탭을 닫거나 다른 탭이 보이면 마지막 상태에서 이어 갑니다. 파일을 더블클릭해 열면 창마다 따로 돕니다.

개발 화면 아래쪽 장치 버튼을 누르면 그 장치의 연결 끊김을 흉내 냅니다. 대시보드 개발 화면에는 서보 과열·전압 이상(리더에 12V)·판정 지연 흉내 버튼이 있습니다.

## 화면

### 조작 화면 (`index.html`)

| ID | 기능 | 위치 |
|---|---|---|
| F-01 | 프로젝트 시작 | 조작반의 주 버튼(라이트는 검정, 다크는 흰색). 가동 중에는 같은 키가 "정지"가 됨 |
| F-02 | EMS / 긴급정지 | 노란 판 위 빨간 버튼. 해제는 "긴급정지 해제" → 확인 창 |
| F-03 | 프로그램 종료 | 조작반 맨 아래. 확인 창 후 서버 정리 → 종료 화면 |
| F-04 | 원점 잡기 | 정지 상태에서만. 각도는 `config/home-position.js` |
| F-05 | 카메라 연결 | 오른쪽 큰 화면 가운데 버튼. 연결되면 주 카메라 영상 + 판정 상자 |
| F-06 | 운전 모드 전환 | 자동 / 수동. 정지 상태에서만. 수동이면 리더암 각도 표시 |

추가 기능
- **생산 통계**: 카메라 아래 검사·양품·불량·불량률
- **로그**: 오른쪽 맨 아래 "로그" 버튼 → 로그 창에서만 봅니다. 창은 오른쪽 보기 영역 위에만 떠서
  열려 있어도 왼쪽 조작반(긴급정지 포함)을 그대로 누를 수 있습니다. 닫기 버튼, Esc, 로그 버튼으로 닫습니다.
- **로그 알림 점**: 창이 닫혀 있는 동안 확인이 필요한 기록(경고·비상)이 생기면 로그 아이콘 오른쪽 위에 빨간 점이 켜지고,
  창을 열면 꺼집니다. 불량 검출은 정상 공정에서 늘 생기므로 점을 켜지 않습니다 (통계에서 확인).
  켜는 기준은 `js/app.js`의 `NOTIFY_LEVELS`, `NOTIFY_SKIP`에서 바꿉니다.
- **고장 표시**: 서버가 고장(`fault`, 예: 서보 과열)으로 멈추면 상태 표시등이 노랑이 되고 이유를 씁니다. 그동안 시작을 누르면 이유를 다시 알려 줍니다.
- **서버 끊김 안내**: 화면 긴급정지가 듣지 않으므로 "로봇팔과 컨베이어의 DC 전원 케이블을 뽑으세요" (키트 설명서의 비상 정지 방법)
- **대시보드 / 다크 모드 버튼**: 오른쪽 맨 아래, 로그 버튼 왼쪽
- **장치 연결 상태** (개발용): 맨 아래 줄 왼쪽. 서버가 알려 준 장치(카메라 여러 대 포함)를 그대로 보입니다

### 대시보드 (`dashboard.html`)

같은 제어함의 계기 쪽이면서, 조작 화면과 같은 조작도 이 화면에서 합니다.
조작(F-01~F-06)은 `js/controls.js`가 조작 화면과 같은 규칙으로 보냅니다: 원점·운전 모드는 정지 상태에서만,
긴급정지 해제는 확인 창을 거치고 해제 뒤에도 정지 상태로 남습니다(D-003·D-004). 실패하면 이유를 윗판 2단의 안내 자리에 씁니다.

| 자리 | 내용 |
|---|---|
| 윗판 1단 (늘 보임) | 상태 → 긴급정지 → 계수기(검사·양품·불량·불량률·분당 처리·판정 시간). 가동 중이면 가동 시간 |
| 윗판 2단 (조작) | 운전 모드(자동/수동) → 시작/정지(긴급정지 바로 아래 같은 폭, 긴급정지 중에는 같은 자리에 "긴급정지 해제") → 원점 잡기 · 안내(실패 이유, 정지해야 쓸 수 있는 이유) · 프로그램 종료 |
| 카메라 | 서버가 알려 준 카메라 전부 (가짜 서버: 위 카메라 + 근접 카메라). 꺼져 있으면 화면 가운데 "카메라 연결", 켜져 있으면 제목 줄에 "카메라 끄기" |
| 분당 판정 | 최근 30분, 분마다 양품(회색)·불량(노랑) 누적 막대. 마우스·화살표 키로 분마다 값, 스크린 리더용 표 |
| 최근 판정 | 번호·시각·판정·신뢰도·판정 시간 4줄 |
| 로봇팔 · 리더암 | 서보 6개씩 위치, 온도(ISA-101 지시계: 정상 범위 띠 + 경고·비상 눈금 + 바늘), 부하, 팔마다 전원 전압 지시계. 벗어나면 그 줄에 "경고"·"비상" |
| 최근 경보 | 경고·비상 기록 4줄 (불량 검출은 빼고) |
| 맨 아래 줄 | 장치 연결, 조작 화면, 다크 모드 |

서버가 끊기면 값을 흐리게 하지 않고, 윗판에 "화면 값은 몇 시 기준"이라고 씁니다 (흐리면 글자 대비가 떨어짐).

맨 아래 줄의 장치 연결 표시는 배포 화면(`?dev=0`)에서도 늘 보입니다 (사용자 결정, 2026-10-12). 조작 화면의 장치 연결 표시는 개발용 그대로입니다.

### 대시보드 탭 시안 (`dashboard-tabs.html`)

조작 화면의 기능과 위 대시보드의 값을 영역마다 탭 하나로 나눠, 그 영역을 한 화면에서 자세히 봅니다.
윗판(상태 → 긴급정지 → 시작/정지 → 계수기)과 아래 줄(조작 화면·다크 모드, 장치 연결, 마지막 경보, 시각)은 어느 탭에서나 보입니다.
조작은 위 대시보드와 같은 `js/controls.js`를 씁니다.

| 묶음 | 탭 | 내용 |
|---|---|---|
| 운전 | 개요 | 공정 흐름(컨베이어 → 촬영 → 판정 → 분류 → 양품 통과 / 불량 상자), 분당 판정 30분, 최근 판정, 지금 이상 |
| | 조작 | 조작반. 운전 판에 왼쪽부터 운전 모드 → 시작 조건 → 시작과 정지. 시작 조건은 서버가 시작을 거절하는 이유와 같은 목록(서버 연결·긴급정지·고장·전원 전압, 컨베이어·로봇팔·주 카메라·리더암)이고 막힌 것이 있으면 할 일을 한 줄로 씀. 아랫줄은 원점(원점 각도와 지금 각도), 카메라(카메라마다·모두 연결/끄기), 긴급정지와 종료 |
| | 생산 | 보는 범위 30·60·120분. 분당 판정, 불량률 추이(평균 점선), 판정 비율, 10분 단위 집계 |
| | 검사 | 카메라 전부(카메라마다 연결/끄기), 최근 판정 60건, 판정 시간(평균·최대·서버 값), 신뢰도 분포 |
| 설비 | 로봇팔 · 리더암 | 서보 6개 표(번호·위치·온도 지시계·부하·전류·힘), 온도 추이 5분, 전원 지시계, 팔 정보. 로봇팔 탭 제목 줄에 원점 잡기. 리더암은 수동 모드에서 로봇팔과의 차이 |
| | 장치 | 장치마다 상태·바뀐 시각·끊긴 횟수·세부, 연결 기록 |
| 기록 | 경보 | 지금 이상(현재 상태에서 뽑음)과 기록(전체·비상·경고·정보로 거르기) |
| | 시스템 | 서버 연결·서버 정보·서버 부하·경고 기준·원점 각도·화면 설정. 개발 화면에는 흉내 단추 |

- **색 위계**: 테(윗판·탭 줄·아래 줄, 두 테마 모두 진한 회색) → 화면 바탕 → 판 머리 → 판. 색상은 지금처럼 신호(빨강·노랑·초록)에만 씁니다.
  선택된 탭은 화면 바탕과 같은 색이라 탭과 그 화면이 이어 보입니다. 색 토큰은 `css/dashboard-tabs.css` 위쪽(다크 값은 두 블록).
- **모서리**: 둥글리지 않습니다. 실제 물건이 둥근 표시등·긴급정지 버섯머리만 원입니다.
- **탭 글자**: 탭마다 그 영역의 가장 나쁜 상태를 붙입니다 — 로봇팔·리더암 `경고`/`비상`/`끊김`, 검사 `끊김`(카메라), 장치 `끊김 n`, 경보는 확인하지 않은 경고·비상 수(경보 탭을 열면 0).
- 탭은 주소 뒤 `#production` 처럼 바로 열 수 있고, 위·아래 화살표·Home·End로 옮깁니다.
- 분당 처리·판정 시간은 윗판 대신 공정 흐름(개요)·생산·검사 탭에 있습니다 (윗판에 시작/정지 키 자리를 내느라).
- 1440×900에서 어느 탭도 화면이 넘치지 않고, 차트·표는 남는 높이만큼 늘어납니다. 1366×768에서는 로봇팔·리더암·시스템 탭이 화면 안에서 조금 넘겨 보고(윗판·탭 줄은 그대로), 960px 아래에서는 탭이 윗판 아래 가로 줄이 됩니다.
- v1은 `docs/v1-snapshot/dashboard-tabs.v1.*`에 남겼고, 검수 결과는 [심플함 보고서 11장](../docs/simplicity-report.md#11-대시보드-탭-시안-2026-10-12).

## 테마 (라이트 / 다크)

처음 열면 PC의 라이트/다크 설정을 따릅니다(`auto`). 오른쪽 맨 아래 **"다크 모드"** 버튼으로 바꿀 수 있고,
켜져 있으면 눌린 모양으로 보입니다. 고른 값은 그 브라우저에 저장되어 새로고침해도 유지되고, 두 화면이 같은 값을 씁니다.

적용 순서: 주소의 `?theme=` → 버튼으로 고른 값 → `js/config.js`의 `theme`.

두 테마는 색 토큰만 다르고 배치·크기·글자는 같습니다. 색 토큰은 `css/base.css` 위쪽의
`prefers-color-scheme: dark` 블록과 `:root[data-theme="dark"]` 블록 두 곳에 같은 값으로 들어 있으니, 고칠 때는 둘 다 고칩니다.

## 디자인 원칙

1. **색은 신호다.** IEC 60073 표시등 의미로만 쓴다. 빨강 = 비상, 노랑 = 이상·진행 중, 초록 = 정상 가동. 나머지는 회색 (ISA-101).
   예외 하나: 로그 버튼의 알림 점은 흔히 쓰는 알림 표시 관례대로 빨강이다.
2. **대담함은 한 곳에만.** 화면에서 튀는 것은 긴급정지 하나. 실제 비상정지 스위치처럼 노란 판 위 빨간 버섯머리. 대시보드도 같다.
3. **가장 중요한 것은 왼쪽 위.** 상태 → 긴급정지 → 시작 순서로 읽힌다. 대시보드는 그다음이 계수기다.
4. **못 누르는 버튼은 이유를 쓴다.** 실패하면 그 버튼 아래에 무엇이 문제이고 어떻게 하면 되는지 쓴다.
5. **장식 없음.** 그림자·그라디언트·블러 0. 깊이는 회색 단계와 1px 테두리로만. 틀은 실제 화면(카메라)에만.
6. **테마가 바뀌어도 안전 색은 그대로.** 긴급정지(노란 판 위 빨간 버튼)는 ISO 13850 고정색이라 두 테마가 같다.
   다크는 위에 올라온 면일수록 밝게(조작반 판 → 보기 영역 → 키·창) 한다.
7. **계기는 정상 범위가 있을 때만.** 대시보드의 지시계는 정상 범위 띠와 경고 눈금이 있는 값(온도·전원 전압)에만 둔다. 범위가 없는 값(위치)은 숫자만.
