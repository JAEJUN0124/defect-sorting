장치 점검

로봇팔 서보, USB 카메라, 아두이노 컨베이어를 이 PC에서 직접 확인합니다. 설치·고장 확인용이며 운영 화면이 아닙니다. Chrome 또는 Edge에서 http://localhost로 열어야 USB 포트를 쓸 수 있습니다.

조작 화면

로봇팔 서보 (USB로 직접 읽기)

서보 드라이버 보드를 이 PC에 꽂고 DC 어댑터 전원을 켠 뒤 포트를 고르세요. 읽기만 합니다. 모터 ID 설정·캘리브레이션·움직이기는 서버 PC에서 LeRobot 명령(lerobot-setup-motors, lerobot-calibrate)으로 합니다. 서버가 같은 포트를 쓰고 있으면 열리지 않으니 서버를 끈 상태에서 쓰세요.

    ID관절모델 위치원시값범위(최소–최대) 전압온도부하 전류힘상태

    로봇팔을 원점 자세로 둔 채 누르면 config/home-position.js에 넣을 내용을 만듭니다 (LeRobot과 같은 식으로 각도를 셈).

    

      
    자세 저장 (로봇팔 작업용)
    
      
    불량품을 집어 상자에 넣는 작업의 자세 값을 모읍니다 (docs/arm-control.md 3장). 로봇팔을 손으로 그 자세에 두고 이름을 고른 뒤 누르세요.
        모은 값은 이 브라우저에 남고, 서버 쪽 로봇팔 설정 파일의 poses에 붙여 넣습니다. 그리퍼 값은 기록만 하고 작업에서는 gripper 단계로 움직입니다.
    
      
    
        
        
        
      
    
      
    
    
    

    
    
    
      
    컨베이어 (아두이노 규약 점검)
    
      
    아두이노 스케치가 컨베이어 시리얼 규약(docs/conveyor-protocol.md)대로 답하는지 봅니다. 115200bps, 줄 끝 \n.
        우노·나노는 포트를 열면 리셋되어 2초쯤 뒤에 답합니다. 서버나 아래 시리얼 콘솔이 같은 포트를 쓰고 있으면 열리지 않습니다.
        연결해 있는 동안 이 화면이 PING을 보내 아두이노의 감시 타이머를 살려 둡니다.

      카메라 (이 PC에 꽂힌 USB 카메라)
      
      
      키트의 720p USB 카메라를 확인하고, HMI가 이 PC의 카메라를 직접 띄울 때(config.js cameras.transport = 'local')
        어느 카메라가 어느 자리인지 정합니다. 서버가 같은 카메라를 열고 있으면 열리지 않을 수 있습니다.
