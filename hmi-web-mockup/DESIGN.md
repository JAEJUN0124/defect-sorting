# Design System: 불량 선별 HMI

대상: 웹 · 작업 화면(조작 화면 하나) · React 19 + Vite 8. 값의 원본은 `css/base.css`(색·글자·간격 토큰, 키·표시등)와 `css/hmi.css`(배치)입니다.

## 1. 분위기

제어함 조작반처럼 차분한 회색 바탕에 신호색만 씁니다. 작업자는 상태를 먼저 읽고, 긴급정지를 바로 누르고, 시작합니다.

1. **색은 신호다.** IEC 60073 표시등 의미로만 쓴다. 빨강 = 비상, 노랑 = 이상·진행 중, 초록 = 정상 가동. 나머지는 회색 (ISA-101).
   예외 하나: 로그 버튼의 알림 점은 흔히 쓰는 알림 표시 관례대로 빨강이다.
2. **대담함은 한 곳에만.** 화면에서 튀는 것은 긴급정지 하나. 실제 비상정지 스위치처럼 노란 판 위 빨간 버섯머리.
3. **가장 중요한 것은 왼쪽 위.** 상태 → 긴급정지 → 시작 순서로 읽힌다.
4. **못 누르는 버튼은 이유를 쓴다.** 실패하면 그 버튼 아래에 무엇이 문제이고 어떻게 하면 되는지 쓴다.
5. **장식 없음.** 그림자·그라디언트·블러 0. 깊이는 회색 단계와 1px 테두리로만. 틀은 실제 화면(카메라)에만.
6. **테마가 바뀌어도 안전 색은 그대로.** 긴급정지(노란 판 위 빨간 버튼)는 ISO 13850 고정색이라 두 테마가 같다.
   다크는 위에 올라온 면일수록 밝게(조작반 판 → 보기 영역 → 키·창) 한다.
7. **긴급정지는 늘 누를 수 있다.** 로그 창은 조작반을 가리지 않는다. 화면이 좁아도 로그 창이 화면 전체를 덮지 않는다.

## 2. 색과 역할

두 테마는 색 토큰만 다르고 배치·크기·글자는 같습니다. 다크 값은 `css/base.css`의 두 블록(`prefers-color-scheme: dark`, `[data-theme="dark"]`)에 같은 값으로 들어 있습니다.

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--c-plate` | `#DADDE1` | `#1E2326` | 조작반 판 (라이트 RAL 7035 / 다크 RAL 7021 계열) |
| `--c-bg` | `#E9EBED` | `#262C31` | 보기 영역 바탕 |
| `--c-key` | `#F7F8F9` | `#343C42` | 키 면, 로그 창, 확인 창 |
| `--c-screen` | `#23282D` | `#0E1113` | 카메라 화면 (다크는 `#737C84` 1px 틀) |
| `--c-ink` / `--c-ink-2` | `#1C2024` / `#555D66` | `#E4E7EA` / `#B3BBC2` | 글자 / 보조 글자 |

## 3. 글꼴

- 제목·본문: IBM Plex Sans KR 400·600. 글꼴 파일은 `css/fonts/`에 있어 인터넷 없이도 나온다 (IBM 공식 woff2, SIL OFL 1.1). 파일을 못 읽으면 Malgun Gothic → Apple SD Gothic Neo
- 크기 단계: 14 / 16 / 21 / 36px
- 숫자(통계·각도·로그 시각)는 `font-variant-numeric: tabular-nums`
- 한글은 낱말 단위로 줄을 바꾼다 (`word-break: keep-all`)

## 4. 컴포넌트

- 키: 높이 64px, 모서리 8px, 키 면 + 1px 테두리. 누르면 `--c-key-down`, 못 누르면 투명 바탕 + `--c-ink-3`
- 시작/정지 키: 높이 88px. 한 키가 지금 할 수 있는 동작을 보인다
- 둘 중 하나 고르는 키(운전 모드·옮길 부품·탑뷰/그리퍼): 고른 쪽만 키 면 + 2px 진한 테두리
- 긴급정지: 노란 판 위 빨간 버섯머리 88px. 잠기면 머리가 어두워지고 0.94로 줄어든다(줄어든 움직임 설정이면 바로 바뀐다). 두 테마가 같다
- 표시등: 14px 원. 진행 중은 1초 깜빡임(줄어든 움직임 설정이면 깜빡이지 않음)
- 안내 글: 키 바로 아래 14px 보조 글자. 실패는 `--c-amber-text` 600
- 카메라 화면: `--c-screen`, 모서리 4px. 화면 위 버튼은 테두리만, 높이 44px
- 창(로그·확인·로그인): 키 면, 1px 테두리, 모서리 8px, 그림자 없음. 확인 창의 첫 초점은 취소
- 맨 아래 줄 키(로그인·다크 모드·로그·프로그램 종료): 테두리 없는 조용한 키 48px. 켜짐·열림은 키 면 + 진한 테두리

## 5. 레이아웃

- 960px 이상: 왼쪽 조작반 `clamp(360px, 30vw, 480px)` + 오른쪽 보기
  - 조작반: 상태 → 긴급정지(잠기면 해제 키) → 시작/정지 → 원점 복귀·원점 잡기 → 운전 모드 → 로봇팔이 옮길 부품 → 맨 아래 프로그램 종료
  - 보기: 카메라(남는 높이 전부) → 팔로워암 각도(수동 모드) → 생산 통계 → 맨 아래 줄(장치 연결 | 로그인 · 다크 모드 · 로그)
- 세로가 낮은 화면(820px 이하, 720px 이하)은 키 높이와 여백을 두 단계로 줄인다. 조작 영역은 44px 아래로 줄이지 않는다
- 960px 미만: 조작반을 위, 보기를 아래로 쌓는다. 로그 창은 맨 아래 줄 바로 위에 끼워 연다
- 간격: 4px 단위 4 · 8 · 12 · 16 · 24 · 32
- 확인 창: 1440·768·390px와 노트북 높이(1280×720, 1366×768·657, 1440×900, 1536×864)에서 조작반이 넘치지 않는지 본다
