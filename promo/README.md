# 홍보 영상

불량품 선별 프로젝트 홍보 영상입니다. 방향이 다른 세 판이 있고, 판마다 가로판(1920 × 1080)과 세로판(1080 × 1920, 쇼츠·릴스용)이 있습니다. 모두 30fps, H.264 영상에 AAC 소리(48 kHz, 320 kbps)를 담았고, 사람 목소리는 넣지 않았습니다.

| 판 | 길이 | 방향 | 결과물 |
|---|---|---|---|
| v3 | 19.5초 | 소개 영상. 검은 바탕에 가운데 큰 글자, 빛나는 테두리, 한 모양이 다음 모양으로 이어지는 모션그래픽 | `out/v3/promo-16x9.mp4` · `out/v3/promo-9x16.mp4` · `out/v3/keyvisual-*.png` |
| v2 | 16초 | 가운데 판정판(낱장이 넘어가는 스플릿 플랩)이 주인공. 화면은 웹 HMI의 회색 조작반과 신호색 | 저장소에 없음 — `node promo/render.mjs --v v2` (세로판은 `--format tall`)로 다시 만듭니다 |
| v1 | 18초 | 포스터 10안의 그림(밤하늘·동심원·로봇팔)을 움직임으로 옮김 | 저장소에 없음 — `node promo/render.mjs --v v1` (세로판은 `--format tall`)로 다시 만듭니다 |

최종은 v3이고, 저장소에는 v3 결과물만 올립니다. v1 · v2는 코드만 있어 위 명령으로 다시 만들 수 있습니다(소리는 먼저 `python promo/v1/music.py`처럼 그 판의 `music.py`를 돌립니다). 세로판은 가로판을 잘라 낸 것이 아닙니다. 같은 시간표로 구도를 따로 잡았습니다. `keyvisual-*.png`는 마지막 프레임이라 썸네일이나 대표 그림으로 씁니다.

## v3 — 소개 영상

사용자가 고른 레퍼런스(Google "AI 모드 만나보기" 15초 광고)의 문법을 따랐습니다. 그 광고의 그림은 쓰지 않고, 장면을 잇는 방식만 가져왔습니다. 완전한 검정 바탕에 흰 글자가 늘 가운데에 크게 있고, 글자 상자 → 버튼 → 화면 → 입력창 → 제목 → 카드 → 빛줄기 → 테두리 → 점 → 마크로 한 모양이 다음 모양으로 바뀌며 이어집니다. 포스터와 HMI의 색은 따르지 않고, 진한 빨강 · 초록 · 파랑 세 가지만 덩어리로 또렷하게 씁니다(카메라 센서의 RGB). 두 색이 맞닿는 곳만 짧게 섞여 가운데가 흐려지지 않고, 빛 번짐은 밝은 곳에만 짧게 둡니다.

장면마다 움직임이 끝나면 글이 읽히도록 한 번 멈춥니다. 큰 타격(넘어감 · 누름 · 불량 · 제목 · 태그라인 · 마크)은 박 위에 둡니다.

| 시간 | 장면 | 멈춤 |
|---|---|---|
| 0~1.5초 | "소개합니다" — 글자가 올라오고, 1.25초부터 정육면체가 위로 구르듯 넘어가 1.5초 박에 다음 면이 앞에 섭니다 | 0.45~1.25초 |
| 1.5~2.5초 | "불량품 선별 시스템" — 레퍼런스의 "AI Mode"처럼 가는 관(튜브) 같은 윤곽선 글자. 가는 글꼴(400)의 바깥 윤곽만 남기고(한 글자 안의 자모끼리 겹친 안쪽 선은 지움) 가운데 흰빛 심과 둘레의 색 빛을 줍니다. 글자마다 빨강 · 파랑 · 초록 중 한 색이고, 빛이 윤곽을 따라 돌며 하나씩 그려진 뒤 2초 박에 모두 파란빛이 됩니다 | 1.8~2.35초 |
| 2.5~5초 | 3D로 크게 기울어진 "시작" 키가 날아와 3초에 눌리고, 카메라가 물러나면 그 키가 웹 HMI 화면의 일부였음이 드러납니다 | 키 3~3.5초, HMI 4~5초 |
| 5~6.5초 | 카메라 화면이 화면 가득 커지고 양품(5.5초) · 양품(5.75초) · **불량**(6초) 판정 | 불량 6~6.5초 |
| 6.5~9초 | 불량 상자가 빛나는 입력창이 되어 "카메라가 양품과 불량을 가리고, 로봇팔이 불량품만 골라 옮깁니다."가 쳐집니다 | 8.25~8.9초 |
| 9~11초 | 그 문장이 큰 제목이 되고 색이 쓸고 지나갑니다. 아래에 시스템 구성 | 10.1~11초 |
| 11~13.25초 | 웹 HMI 기능 카드 여덟 장이 올라와 멈췄다가 빠르게 빠집니다 | 11.5~12.75초 |
| 13.25~14초 | 빛줄기 여덟 가닥이 화면을 가릅니다 | |
| 14~16초 | 빛나는 테두리 안에 "불량을 찾는 눈, 골라내는 손" | 14.35~15.9초 |
| 16~19.5초 | 테두리가 점으로 줄어들었다가 16.5초에 학교 마크로 터지고, 학교 · 팀 이름 | 17.3~19.5초 |

2D로 그린 층과 카드를 WebGL(`v3/gl.js`)로 겹쳐 정육면체 · 3D 기울기와 빛 번짐(블룸)을 넣고, 큰 박자(누름 · 제목 · 태그라인 · 마크)마다 화면이 살짝 튑니다. 음악은 120 BPM 펑키 하우스(D 장조 둘레)이고, 화음이 바뀌는 때와 북을 비우는 구간도 시간표의 큐에서 읽습니다. 타이핑 소리는 글자 36개의 시각에, 빛줄기 소리는 줄기마다 방향대로 지나가게 놓았습니다. v3는 음악까지 서브 에이전트 없이 만들었습니다.

## v2 — 판정판

v1이 포스터 그림에 많이 기댄 데다 글자가 작고 한쪽에 있어 잘 안 보였습니다. v2는 포스터 그림을 쓰지 않고, **글자를 화면 가운데의 큰 판정판에** 둡니다. 낱장이 박자에 맞춰 넘어가며 판정과 동작을 하나씩 보여 줍니다.

화면 모습은 팀이 만든 웹 HMI의 디자인 규칙(`hmi-web-mockup/DESIGN.md`)에서 가져왔습니다. 차분한 회색 조작반에 색은 신호에만 씁니다(초록 = 정상·양품, 노랑 = 이상·불량). 글꼴도 HMI와 같은 IBM Plex Sans KR입니다. 카메라·서버·컨베이어·로봇팔은 판 둘레에 선으로 그린 도면처럼 두고, 지금 일하는 기계만 밝게 그립니다.

| 시간 | 판 | 장면 |
|---|---|---|
| 0~2초 | 양품 · 양품 · 양품 · **불량** | 부품이 박마다 카메라 아래에 내려앉고 찍힙니다. 네 번째에 판이 노랗게 바뀌고 화면 테두리에 노란 신호. 박자가 끊깁니다 |
| 2~4초 | 카메라가 / **본다** | 시선이 불량에 모이고, 모서리 괄호가 오므라들고, 훑는 선이 지나간 뒤 3초에 노란 검출 상자가 잠깁니다 |
| 4~6초 | 서버가 / **판단한다** | 데이터가 레일을 타고 서버로 올라갔다 돌아오고, 5초에 금이 노랗게 그려집니다 |
| 6~8초 | 로봇팔이 / **골라낸다** | 서버의 신호가 팔로 가고, 팔이 7초에 불량품을 집어 불량함에 놓습니다 |
| 8~10초 | 양품 × 4 | 박자가 돌아옵니다 |
| 10~12초 | 웹 HMI로 / **운전한다** | 장면이 웹 HMI의 카메라 화면(탑뷰) 안으로 줄어들고, 판은 위의 제목줄이 됩니다 |
| 12~16초 | **불량을 찾는 눈, 골라내는 손** | 타격과 함께 큰 판이 들어오고, 13초에 제목이 물결처럼 내려앉습니다. 학교·팀 이름 |

판의 글은 세 낱말 "본다 · 판단한다 · 골라낸다"로 시스템이 하는 일을 순서대로 말하고, 끝에서 포스터와 같은 제목으로 묶습니다. 판정판은 첫 프레임부터 또렷하게 "양품"을 보이고, 다른 글이 들어올 때만 잠깐 낱장이 돌아갑니다.

## v1 — 포스터 그림

전할 말은 "불량을 찾는 눈, 골라내는 손" 하나입니다. 보는 사람이 먼저 불량을 찾게 하고, 그다음 카메라(눈)와 로봇팔(손)이 그 일을 해내는 것을 보여 줍니다.

| 시간 | 장면 | 소리 |
|---|---|---|
| 0~4초 | 똑같은 부품 수백 개가 8분음표마다 한 칸씩 움직이고, 하나에만 산호색 금이 있습니다. 자막은 "이 중 하나는 불량입니다." → "찾으셨나요?" | 컨베이어처럼 또각거리는 박자 16번. 3.5초에 한 번 어긋남 |
| 4~7초 | 포스터의 동심원(카메라의 눈)이 피어나 훑다가 불량에 오므라들며 초점을 맞춥니다. "찾는 / 눈". 금 간 곳으로 밀고 들어갑니다 | 훑는 소리, 5초에 맑은 고정음 A5 |
| 7~10초 | 금이 갈라지고 그 꺾인 선이 로봇팔이 됩니다(금은 팔과 같은 비율). 9초에 불량품을 집습니다. "골라내는 / 손" | 갈라지는 소리, 서보, 집는 소리 |
| 10~14초 | 박마다 "이송 · 촬영 · 판정 · 분류". 12초에 이 장면이 웹 HMI의 카메라 화면이었음이 드러납니다 | 본 비트 Dm – B♭ – F – C |
| 14~18초 | 포스터 키 비주얼이 맞춰지고 제목과 학교·팀 이름 | 가장 큰 타격, 소리 로고 C5 → F5 → A5 |

색과 도형은 `poster/v10/poster.html`의 값(남색·산호·연분홍, 동심원 9색, 카메라·로봇팔·컨베이어 좌표)을 그대로 씁니다. 측정값은 통합 음량 −14.0 LUFS, 트루 피크 −1.3 dBTP, 큐 시각 오차 1 ms 안입니다.

## 사실 확인 (두 판 공통)

- 성능 수치(정확도·속도)는 쓰지 않았습니다. 확인한 값이 없기 때문입니다.
- 화면의 기능은 실제 구성과 같습니다. 카메라 두 대(탑뷰·그리퍼), 양품/불량 두 가지 판정(D-005), 서버가 판정하고 HMI는 판정하지 않음(D-018), 로봇팔이 옮길 부품 고르기, 자동 운전·긴급정지·원점, 장치 연결 줄(D-008).
- HMI 통계 숫자는 보여 주기 위한 예시입니다.

## 만들기

먼저 패키지를 받습니다.

```bash
npm --prefix promo install
```

ffmpeg가 PATH에 없으면 `FFMPEG` 환경 변수로 경로를 줍니다. 크롬이나 엣지는 설치된 것을 찾아 씁니다. 다른 경로이면 `CHROME` 환경 변수로 줍니다. `--v`를 빼면 최신 판(v3)입니다. v3는 WebGL2를 쓰므로 그래픽 카드가 있는 PC에서 빠릅니다. v3 음악은 `python promo/v3/music.py --ffmpeg <ffmpeg 경로>`로 만들면 −14 LUFS에 맞춰집니다.

```bash
python promo/v2/music.py
```

```bash
node promo/render.mjs --v v2
```

```bash
node promo/render.mjs --v v2 --format tall
```

| 명령 | 하는 일 |
|---|---|
| `python promo/v2/music.py` | 그 판의 음악과 효과음을 만듭니다: `out/v2/soundtrack.wav`, 음악·효과음 따로 `out/v2/stem_*.wav`. `--lufs`·`--tp`로 음량, `--bits 24`로 24비트 |
| `node promo/render.mjs --v v2` | 가로판을 그리고 소리를 입힙니다 (프레임마다 16번 겹쳐 모션 블러, 한 프레임 약 0.8초) |
| `node promo/render.mjs --v v2 --format tall` | 세로판 |
| `node promo/render.mjs --v v2 --stills 5,9.2,15.9` | 그 시각(초)의 정지 화면만 `out/v2/stills/`에 PNG로 |
| `node promo/render.mjs --v v2 --mux` | 소리만 바꿨을 때, 그려 둔 영상(`out/v2/.video-*.mp4`)에 소리만 다시 입힙니다 |
| `node promo/v2/timeline.mjs` | v2 시간표를 바꾼 뒤 소리 쪽이 읽는 `v2/timeline.json`을 다시 만듭니다 |
| `node promo/tools/serve.mjs` | 미리보기 서버. `http://127.0.0.1:5180/promo/player.html?v=v2`에서 소리와 함께 재생하고 아무 시각이나 봅니다 (`&format=tall`, `&t=초`). 실시간으로 그리므로 PC에 따라 끊길 수 있고, 모션 블러는 렌더한 MP4에만 있습니다 |

## 구조

| 파일 | 내용 |
|---|---|

| `v2/timeline.mjs` | v2 시간표의 원본. 판에 뜨는 글, 컨베이어가 내려앉는 때, 낱장 하나하나가 넘어가는 때를 정합니다 |
| `v2/timeline.json` | 위에서 만든 사본. 소리 쪽이 낱장 소리를 낱장마다 맞추려고 읽습니다 |
| `v2/scene.js` | v2 장면 |
| `v2/music.py` | v2 음악·효과음 합성 (numpy·scipy) |
| `v1/timeline.json` · `v1/scene.js` · `v1/music.py` | v1. 장면 안의 시각은 `timeline.json`과 맞춰 `scene.js`에 적혀 있어 바꾸면 두 곳을 함께 고칩니다 |
| `out/v1/` · `out/v2/` · `out/v3/` | 결과물 |

모든 장면은 시각 t만으로 정해져서 어느 프레임이든 따로 그릴 수 있습니다.
