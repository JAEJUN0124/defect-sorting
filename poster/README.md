# 프로젝트 포스터

불량품 선별 프로젝트 포스터입니다. A1(594 × 841 mm)을 기준으로 그렸습니다. A 규격은 가로세로 비율이 같아서 A0~A3 어느 크기로 뽑아도 그대로 맞습니다.

| 파일 | 내용 |
|---|---|
| `poster.pdf` | 인쇄용. 글꼴이 파일 안에 들어 있어 다른 PC에서도 똑같이 보입니다 |
| `poster.png` | 미리보기 (1188 × 1682) |
| `poster.svg` | 원본 벡터. 일러스트레이터에서 열 수 있지만, 그 PC에 글꼴 Noto Sans KR이 있어야 합니다 |
| `build.py` | 위 세 파일을 만드는 스크립트 |
| `assets/daelim-authority-mark.svg` | 대림대학교 Authority Mark. 학교가 배포한 .ai 파일에서 벡터를 그대로 뽑았습니다 |
| `v1/` | 1안. 그림과 제목만 있고 동작 설명은 없습니다 |
| `v2/` | 2안. 동작 과정·시스템 구성을 소제목과 여러 줄 설명으로 넣었습니다 |
| `v3/` | 3안. 지금 `build.py`가 만드는 안을 따로 떠 둔 것입니다. 문구를 줄이고 띠 색으로 정보를 나눴습니다 |

`v1/`~`v3/`에는 결과물(PDF·PNG·SVG)만 있습니다. `build.py`는 늘 최신 안을 이 폴더 바로 아래에 만들고, 1·2안은 다시 만들지 못합니다. 고쳐야 하면 각 폴더의 `poster.svg`를 직접 엽니다.

## 다시 만들기

```bash
python poster/build.py
```

Edge나 Chrome, 그리고 글꼴 Noto Sans KR이 있어야 합니다. 문구는 `build.py` 맨 위의 `TEXT`에서 고칩니다.

## 구성

배경을 세 띠로 나눕니다.

| 띠 | 배경 | 내용 |
|---|---|---|
| 위 | 남색 | 학교·사업명, 제목, 부제, 그림 |
| 가운데 | 산호 | 동작 과정 세 단계 |
| 아래 | 남색 | 시스템 구성, 학과·팀원 |

- 그림: 검사 자리(불량품이 있는 곳) 한 점에서 모든 원이 컨베이어에 닿습니다. 라인 전체의 시선이 불량품 하나에 모이고, 로봇팔이 그것을 집어 올리는 장면입니다. 다른 부품은 밝은 색, 불량품만 남색이고 모서리가 깨져 있습니다.
- 그림 속 번호 ①②③(들어오는 부품, 카메라, 불량 상자)은 아래 세 단계와 같은 순서로 왼쪽에서 오른쪽으로 놓입니다. 세 단계 이름을 이어 읽으면 "옮기고, 보고, 골라낸다."가 됩니다.
- 동작 과정은 [공정 순서](../docs/line-sequence.md)의 "부품마다 멈춤" 방식, 시스템 구성은 [API](../docs/API.md)와 [로봇팔 문서](../docs/robot-arm.md)를 따릅니다. 이 문서들이 바뀌면 `TEXT`도 맞춰 고칩니다.

글자 색은 역할로 나눕니다.

| 역할 | 남색 띠 위 | 산호 띠 위 |
|---|---|---|
| 핵심 (제목, 단계, 장치 이름, 팀원) | 흰색 | 남색 |
| 강조 (부제, 단계 번호, 연결 방식) | 산호 | 남색 원 안의 산호 |
| 보조 (사업명, 하는 일, 학과) | 흐린 크림 `MUTED` | 남색 |

## 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 남색 | `#051230` | 하늘, 글자 |
| 산호 | `#F48067` | 바닥, 빛의 가운데 고리 |
| 노을색 | 두 색을 섞은 다섯 단계 (`dusk()`) | 빛의 바깥 고리 |
| 밝은 산호 | 산호에 흰색을 섞은 색 | 빛의 가운데, 부품, 별 |
| 학교 하늘색 | `#0095C8` (PANTONE 639 C) | Authority Mark. 학교 원본 색 그대로입니다. 남색 위에서 대비 5.4:1, 산호 위에서는 1.3:1이라 남색 하늘에 둡니다 |

`dusk()`의 `turn`이 섞는 방식을 정합니다. 0이면 두 색을 곧게 섞어 가운데가 탁한 갈색이 되고, 1이면 보라 쪽으로 돌아 더 몽환적이지만 보라가 세 번째 색처럼 보입니다. 지금 값은 그 가운데인 0.5입니다.

## 인쇄할 때

- 색은 RGB입니다. 인쇄소가 CMYK로 바꾸면 남색과 산호가 조금 달라질 수 있습니다.
- 재단 여유(도련)는 없습니다. 배경색이 종이 끝까지 닿습니다.
