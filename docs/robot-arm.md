# 로봇팔 키트와 HMI

로봇팔은 Brain Us "AI Robot ARM Edu Kit"(모델 AI-Robot-001)입니다. 오픈소스 로봇팔 SO-ARM101 설계를 바탕으로 만든 6관절 교육용 키트이고,
PC와 USB로 연결해 LeRobot 프레임워크로 움직입니다. 이 문서는 키트 구성, HMI가 근거로 쓴 사실, HMI에 반영한 것, 설치 순서를 정리합니다.
서버가 로봇팔에 무엇을 시키는지(동작 단위·자세·멈출 때)는 [로봇팔 제어 약속](arm-control.md)에 있습니다.

출처
- 키트 설명서 (사용자가 보낸 사진 2장, 2026-10-12): 구성품, 전원, 안전 및 주의사항, 권장 OS
- LeRobot SO-101 문서: <https://huggingface.co/docs/lerobot/so101> (조립·모터 설정·캘리브레이션)
- LeRobot 코드 (main, 2026-10-12에 읽음): `robots/so_follower`, `teleoperators/so_leader`, `motors/feetech/feetech.py`·`tables.py`, `motors/motors_bus.py`
- Feetech STS 메모리 표 단위·기본값: 제3자 정리 문서 "FEETECH STS Servo – Memory Table Analysis"(aifitlab wiki) — 주소는 LeRobot `tables.py`와 같음

## 1. 키트 구성

| 구성품 | 수량 | 쓰임 |
|---|---|---|

| 서보 STS3215-C001 (7.4V, 1:345) | 1 | 리더암 어깨 들기 |

| 서보 STS3215-C046 (7.4V, 1:147) | 3 | 리더암 손목 굽힘·손목 회전·그리퍼 |
| 리더암·팔로워암 3D 뼈대 | 각 1세트 | — |
| 탑 뷰 카메라 마운트 | 1세트 | 위에서 내려다보는 카메라 |
| 리더암 전원 어댑터 DC 7.5V 3A | 1 | 리더 서보 6개 |

리더암의 서보 배치는 LeRobot SO-101 리더 표(어깨 회전 1/191 · 어깨 들기 1/345 · 팔꿈치 1/191 · 손목 굽힘·손목 회전·그리퍼 1/147)와 같습니다.
리더는 손으로 쉽게 움직이도록 감속비가 낮은 서보를 섞었고, 팔로워는 모두 1/345입니다.

## 2. HMI가 근거로 쓴 사실

| 항목 | 값 | 근거 | HMI에서 쓰는 곳 |
|---|---|---|---|
| 관절 이름·모터 번호 | `shoulder_pan`(1) `shoulder_lift`(2) `elbow_flex`(3) `wrist_flex`(4) `wrist_roll`(5) `gripper`(6) | LeRobot `so_follower.py`·`so_leader.py` | 원점 각도, 서보 표, 장치 점검 |
| 서보 통신 | 1,000,000bps, Feetech 프로토콜 0(낮은 바이트 먼저), 한 바퀴 4096칸 | LeRobot `feetech.py` `DEFAULT_BAUDRATE`, `tables.py` | `config/robot.js bus`, `js/feetech.js` |
| 모델 번호 | STS3215 = 777 | LeRobot `MODEL_NUMBER_TABLE` | 장치 점검의 모델 확인 |
| 서보 메모리 주소 | 위치 56, 부하 60, 전압 62, 온도 63, 상태 65, 전류 69, 최소·최대 위치 9·11, 홈 오프셋 31 | LeRobot `STS_SMS_SERIES_CONTROL_TABLE` | `js/feetech.js` |
| 단위 | 전압 0.1V, 온도 °C, 부하 0.1%(10번 비트가 방향), 전류 6.5mA, 위치 15번 비트가 방향 | 메모리 표 정리 문서, LeRobot `STS_SMS_SERIES_ENCODINGS_TABLE` | 서보 값 해석 |
| 서보 자체 과열 보호 | 최대 온도 기본 70°C | 메모리 표 정리 문서 | 경고 기준을 그보다 낮게(55·65°C) |
| 캘리브레이션 | 가운데 자세에서 홈 오프셋을 정해 그때 위치가 2047이 되게 하고, 관절마다 움직인 범위(최소·최대)를 서보에 써 둠. 손목 회전은 한 바퀴(0~4095) | LeRobot `calibrate()`, `write_calibration()` | 장치 점검의 "캘리브레이션 전" 판단 |
| 관절 값 단위 | `use_degrees=True`(지금 기본)면 도 = (위치 − 가운데) × 360 / 4095, 가운데 = (최소 + 최대) / 2. 그리퍼는 늘 0~100. `False`면 -100~100 | LeRobot `motors_bus.py _normalize`, `config_so_follower.py` | 원점 값 만들기, `joint_unit` |
| 위치 읽기 | 현재 위치 = 실제 위치 − 홈 오프셋 (서보가 계산) | LeRobot `feetech.py` 주석 | — |

## 3. HMI에 반영한 것

| 반영 | 파일 | 내용 |
|---|---|---|
| 키트 설정 | `hmi-web-mockup/config/robot.js` | 팔 두 개(로봇팔 = 팔로워 12V, 리더암 7.4V급)의 서보 모델·감속비·ID, 전원 기준, 온도 경고 기준, 관절 단위 |
| 전원 확인 | 같은 파일 `supply` | 어댑터 정격 ±10%를 벗어나면 경고, **리더암에 12V가 들어오면(10V 초과) 비상**, 팔로워에 7.5V가 들어오면(9V 미만) 비상 |
| 과열 확인 | 같은 파일 `limits` | 55°C 경고, 65°C 비상 (서보가 스스로 힘을 빼는 70°C 전에 알림) |
| 비상정지 안내 | `config/robot.js hardwareStop`, `js/i18n/ko.js` | 서버가 끊기면 "로봇팔과 컨베이어의 DC 전원 케이블을 뽑으세요" (키트 설명서의 비상 정지 방법) |
| 대시보드 | `dashboard.html` | 로봇팔·리더암 서보 6개씩 위치·온도(ISA-101 지시계)·부하, 팔마다 전원 전압 |
| 서보 경고 기록 | `js/store.js` | 서버가 서보 경고를 안 보내면 HMI가 서보 상태 값으로 판단해 기록 |
| 원점 | HMI가 저장 (브라우저 저장소, `js/home.js`) | 수동 모드에서 리더암으로 팔을 원하는 자세에 둔 뒤 "원점 잡기"로 저장, 자동 모드에서 "원점 복귀"로 그 각도를 서버에 보내 이동 ([xml-protocol.md 3장](xml-protocol.md#3-원점--hmi가-저장-사용자-2026-10-14)) |
| 카메라 두 대 | `js/camera.js`, `js/config.js cameras` | 위·근접 카메라를 대시보드에 함께, 조작 화면에는 주 카메라 |
| 장치 점검 | `tools/devices.html`, `js/feetech.js` | 아래 5장 |

## 4. 설치 순서와 역할

LeRobot 명령(모터 ID 설정·캘리브레이션·원격 조작)은 **서버 PC에서** 합니다(서버 담당 또는 같이). HMI 쪽 도구는 그 결과를 **확인만** 합니다.

| 순서 | 어디서 | 할 일 | 확인 |
|---|---|---|---|
| 1 | 서버 PC | `pip install -e ".[feetech]"` (LeRobot) | — |
| 2 | 서버 PC | `lerobot-find-port` — 팔마다 USB 포트 찾기 | 장치 점검의 "USB 포트 고르기"에 칩 이름(CH340·CH343 등)이 보임 |
| 3 | 서버 PC | `lerobot-setup-motors` — 서보 하나씩 꽂아 ID 1~6, 1Mbps로 (팔로워·리더 각각) | 장치 점검에서 "서보 6개(ID 1~6)가 모두 답합니다" |
| 4 | — | 어댑터 확인: 리더 7.5V, 팔로워 12V | 장치 점검에서 "전원 ○V (정격과 맞음)" |
| 5 | 서버 PC | `lerobot-calibrate` — 가운데 자세 → 관절마다 끝까지 (팔로워·리더 각각) | 장치 점검에서 "최소·최대 위치가 기록되어 있습니다" |
| 6 | 서버 PC | `lerobot-teleoperate` — 리더로 팔로워 움직여 보기 | — |
| 7 | HMI | 서버를 끈 상태에서 장치 점검의 "자세 저장" — 로봇팔을 작업 자세(`wait`·`above_pick`·`pick`·`above_bin`·`rest`)에 차례로 두고 저장 → 서버 쪽 로봇팔 설정의 `poses`에 붙여 넣기 ([로봇팔 제어 약속](arm-control.md) 3장) | 서버의 불량품 옮기기 작업이 그 자세로 움직임 |
| 8 | 서버 PC | `lerobot-find-cameras opencv` — 카메라 번호 | 장치 점검의 카메라 찾기에서 1280×720이 나오는지 |
| 9 | HMI | 아두이노 스케치를 올린 뒤 장치 점검의 "컨베이어 규약 점검" ([컨베이어 시리얼 규약](conveyor-protocol.md)) | 점검 줄이 모두 "정상" |
| 10 | HMI | 서버를 켜고 서버 점검 → `config.js`에 제안 값 반영 | 조작 화면·대시보드가 서버 값으로 움직임 |
| 11 | HMI | 조작 화면에서 수동 모드 → 리더암으로 로봇팔을 원점으로 쓸 자세에 두고 "원점 잡기" (확인 창) | 대시보드 탭 시안의 조작·시스템 탭에 저장한 원점과 시각이 보임. 원점은 그 PC의 브라우저에 저장되므로 HMI를 쓸 PC에서 함 |

서보 버스(USB 포트)와 카메라는 **한 프로그램만** 열 수 있습니다. 장치 점검은 서버를 끈 상태에서 쓰세요.

## 5. 장치 점검 도구 (`tools/devices.html`)

Chrome·Edge에서 `http://localhost:5173/tools/devices.html` (USB 포트는 Web Serial이라 이 두 브라우저와 localhost·https에서만 됩니다).

- **로봇팔 서보**: 포트를 고르면 ID 1~10을 찾고, 서보마다 모델·현재 위치(도·%)·원시값·캘리브레이션 범위·전압·온도·부하·전류·힘·상태 비트를 읽습니다.
  "계속 읽기"로 0.3초마다 갱신. 점검 결과로 빠진 ID, ID 설정 전(모두 1), 모델 다름, 어댑터 잘못 꽂음, 캘리브레이션 전, 과열, 이상 비트를 알려 줍니다.
  **읽기만 합니다** — ID·통신 속도 바꾸기, 힘 켜기, 움직이기는 하지 않습니다.
- **자세 저장**: LeRobot과 같은 식으로 각도를 계산해 로봇팔 작업 자세를 이름별로 모아 서버 쪽 로봇팔 설정의 `poses` 모양으로 만듭니다. 모은 값은 그 브라우저에 남습니다 ([로봇팔 제어 약속](arm-control.md) 3.4장).
- **컨베이어 규약 점검**: 아두이노 스케치가 [컨베이어 시리얼 규약](conveyor-protocol.md)대로 답하는지 차례로 시험합니다 (응답 모양, 모르는 명령, 잠금, 감시 타이머, 기능별 명령). 가동·정지·잠금 단추로 손으로 보내 볼 수도 있고, 하드웨어 없이 "가짜 컨베이어로 시험"할 수 있습니다.
- **카메라**: 이 PC에 꽂힌 카메라 목록, 미리보기, 실제 해상도·프레임 수. HMI가 카메라를 직접 띄울 때(`cameras.transport: 'local'`) 카메라마다 자리(id)를 저장합니다.
- **서버 영상 주소 시험**: 서버가 알려 준 영상 주소를 판정 화면과 같은 코드로 열어 봅니다 (MJPEG·스냅샷·웹소켓·WebRTC·video).
- **시리얼 콘솔**: 아두이노 컨베이어 스케치가 주고받는 글자를 보고 보낼 수 있습니다 (보낸 글자로 컨베이어가 움직일 수 있음).
- 하드웨어 없이 화면을 시험하는 "가짜 서보로 시험", "가짜 카메라로 시험"이 있습니다.

## 6. 안전

- **비상 정지**: 키트 설명서는 "DC 케이블 분리 방법을 익힌 뒤 사용"하라고 합니다. HMI의 화면 긴급정지는 서버를 거치므로 안전 장치가 아닙니다.
  로봇팔 두 개와 컨베이어의 DC 전원을 한 번에 끊는 버섯머리 비상정지 스위치를 다는 것을 권합니다(달면 `hardwareStop: 'button'`).
- **어댑터를 바꿔 꽂지 않기**: 리더(7.4V급 서보)에 12V를 넣으면 서보가 상할 수 있습니다. HMI는 서보 전압으로 이를 알아채 "비상"으로 기록하고, 가짜 서버는 수동 모드 시작을 거절합니다(`POWER_ABNORMAL`).
- **과열**: 설명서는 상하좌우 10cm 이상 통풍을 확보하라고 합니다. 오래 버티는 자세(어깨 들기·팔꿈치)는 온도가 오르기 쉬워, 대시보드에서 온도를 지시계로 봅니다.
- **젖은 손·파손된 케이블 금지** (설명서).

## 7. 확인하지 못한 것

- 실제 키트로는 아직 아무것도 시험하지 않았습니다. `js/feetech.js`는 LeRobot 코드의 주소·단위와 가짜 서보로만 확인했습니다.
- 서보 드라이버 보드의 정확한 칩은 모릅니다(설명서에 없음). 장치 점검이 USB 번호로 알려 줍니다.
- 경고 기준(55·65°C, 어댑터 정격 ±10%, 리더 10V·팔로워 9V)은 직접 정한 값입니다. 쓰면서 고칩니다.
- 두 번째 카메라의 위치(근접·옆·손목)는 정하지 않았습니다. 키트에는 탑 뷰 마운트만 있습니다. 화면 이름은 `config.js cameras.labels`에서 바꿉니다.
