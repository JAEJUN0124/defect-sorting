# DECISIONS
현재 유효한 결정만 둔다. 형식은 handoff 문서 규격을 따른다.

## D-001 HMI는 웹으로 만든다
- 범위: HMI 전체
- 결정: 최종 형태는 웹(브라우저) HMI다. 처음 계획한 Python PyQt/PySide 데스크톱 버전은 만들지 않는다.
- 근거: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md

## D-002 HMI와 서버는 소켓으로 통신하고 데이터는 XML이다
- 범위: HMI↔서버
- 결정: 명령과 상태·판정·이벤트를 소켓으로 주고받고, 데이터 형식은 XML이다. 명령 결과는 서버가 리플라이로 보낸다. 소켓 종류와 XML 형식은 서버 담당과 정한다.
- 근거: 사용자 2026-10-13 · HISTORY/2026-10-13-comm-socket-xml.md
- 관련 문서: docs/API.md

## D-003 운전 모드 규칙
- 범위: 운전 모드 전환(F-06)
- 결정: 자동↔수동 전환은 정지 상태에서만 한다. 수동 모드는 사람이 리더암을 직접 움직이는 텔레오퍼레이션이며, HMI에 로봇팔 조그 버튼을 두지 않는다.
- 근거: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md

## D-004 긴급정지 해제는 해제 버튼 + 확인 창
- 범위: 긴급정지(F-02)
- 결정: 해제는 "긴급정지 해제" 버튼과 확인 창을 거친다. 해제 뒤에도 라인은 정지 상태로 남고 저절로 다시 가동하지 않는다.
- 근거: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md

## D-005 판정은 양품/불량 두 가지
- 범위: 판정·생산 통계
- 결정: 불량 종류(긁힘·오염 등)는 나누지 않는다.
- 근거: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md

## D-006 화면 기본 조건
- 범위: HMI 화면
- 결정: 로그인은 두지 않는다. 문구는 한국어만 쓰되 영어를 추가할 수 있는 구조로 둔다. 노트북·데스크톱을 우선으로 하되 다른 화면 크기에서도 깨지지 않게 한다.
- 근거: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md

## D-007 원점 잡기는 수동 모드에서 지금 자세를 저장하고, 원점 복귀는 따로 둔다
- 범위: 원점(F-04)
- 결정: "원점 잡기"는 수동 모드에서 리더암으로 로봇팔을 원하는 자세에 둔 뒤 그 자세를 원점으로 저장하며, 자동 모드에서는 비활성화한다. 저장 전에 확인 창을 띄운다. 저장된 원점으로 옮기는 "원점 복귀"는 별도 버튼으로 자동 모드·정지 상태에서 쓰고, 긴급정지·고장 뒤에는 원점 복귀를 해야 시작한다.
- 근거: 사용자 2026-10-13 · HISTORY/2026-10-13-home-teach-decision.md

## D-008 장치 연결 상태 표시는 계속 보인다
- 범위: HMI 화면
- 결정: 장치 연결 상태(서버·컨베이어·로봇팔·리더암·카메라)는 개발이 끝난 뒤에도 계속 보인다. "(개발용)" 같은 표시 문구는 두지 않는다.
- 근거: 사용자 2026-10-17 · HISTORY/2026-10-17-screen-text-decisions.md (이전 결정: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md)

## D-009 로그는 버튼으로 여는 전용 창에서만 본다
- 범위: 로그·화면 배치
- 결정: 화면에 상시 로그 영역을 두지 않고 그 자리는 카메라 영상이 쓴다. 로그는 오른쪽 맨 아래 "로그" 버튼으로 여는 창에서만 본다. 창이 닫혀 있는 동안 확인이 필요한 기록이 생기면 로그 아이콘에 빨간 점을 표시한다.
- 근거: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md

## D-010 라이트·다크 테마와 화면 테마 버튼
- 범위: HMI 화면
- 결정: 라이트·다크 두 테마를 둔다. 처음에는 PC 설정을 따르고, 화면의 "다크 모드" 버튼으로 바꿀 수 있다.
- 근거: 사용자 2026-10-07 · HISTORY/2026-10-12-hmi-decisions.md

## D-016 HMI 화면은 React로 만든 조작 화면 하나다
- 범위: HMI 화면(`hmi-web-mockup/react/`)
- 결정: 대시보드는 두지 않고 조작 화면 하나만 둔다. 조작 화면은 React로 만들고, 동작은 React로 옮기기 전 조작 화면과 같게 한다.
- 근거: 사용자 2026-10-17 · HISTORY/2026-10-17-react-single-screen-decision.md

## D-017 장비망 밖에서는 Cloudflare로 HMI를 연다
- 범위: HMI 화면을 내주는 곳과 장비망 밖에서의 접속
- 결정: 장비망 밖에서는 사용자의 도메인(`hmi.hypefree.net`)으로 연다. 화면 파일은 Cloudflare Worker가 내주고, 서버로는 Cloudflare Tunnel로 필요한 경로(`/ws/hmi`, 서버가 HTTP로 내주는 영상)만 넘기며, 앞에 Cloudflare Access(허락한 사람만)를 둔다. 메인 서버에서 화면을 띄우는 방식은 쓰지 않는다.
- 근거: 사용자 2026-10-17 · HISTORY/2026-10-17-cloudflare-decision.md
- 관련 문서: docs/cloudflare.md

## D-018 로봇팔이 옮길 부품은 HMI에서 고르고, HMI는 고른 값만 보낸다
- 범위: 로봇팔이 옮길 부품(양품·불량품) 선택
- 결정: 작업자가 HMI에서 양품·불량품 중 로봇팔이 옮길 쪽을 고르고, HMI는 고른 값만 서버에 보낸다. HMI는 부품을 판정하지 않으며, 그 값을 어떻게 쓸지는 서버·장비 쪽이 정한다. 고른 값은 정지 상태에서만 바꾼다.
- 근거: 사용자 2026-10-17 · HISTORY/2026-10-17-camera-sort-decisions.md
- 관련 문서: docs/xml-protocol.md, docs/hmi-server-answer-1.md

- 결정: 카메라 화면은 하나만 두고 탑뷰·그리퍼를 버튼으로 바꿔 본다.
