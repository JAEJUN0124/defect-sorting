# 프로그램 종료는 HMI 화면만 끝내기로 함 (D-015 추가)

## 요약
- 그때까지 HMI는 `ProgramStop`을 프로그램 종료로 가정해, 프로그램 종료 때 서버에 `ProgramStop`을 보냈다. 정지 키는 요청안 이름 `Stop`을 보냈다 (HISTORY/2026-10-14-server-xml-v1.md).
- 서버 담당은 회신 1장 Q1에서 `ProgramStop`은 컨베이어·로봇팔 정지 요청이고 HMI 화면 종료를 뜻하지 않는다고 답했다. 그리고 종료 화면이 꼭 필요하면 장비 정지 완료와 화면 종료를 잇는 규칙을 따로 정하자고 했다 (회신 5장 1번).
- 사용자가 정지와 종료는 다르고, 프로그램 종료는 HMI만 끝내는 것이라고 정했다. DECISIONS에 D-015로 추가했다.
- 그래서 프로그램 종료는 확인 창 → 서버 연결을 닫고 종료 화면을 남기며 서버에는 아무것도 보내지 않는다. 라인·장비를 멈추는 것은 정지 키(가동 중에 시작 키가 "정지"로 바뀜, `ProgramStop`)와 긴급정지다. 서버 회신이 제안한 `Stop` 별칭과 종료 완료 알림은 HMI에 필요 없다고 답장 0.5에 썼다.

## 근거
- 사용자: "정지와 종료는 다르게 하고 있는거지? 그리고 아래있는 프로그램 종료 이야기 하는거면 hmi만 끝내는거야." — 회신의 `ProgramStop` 의미를 두고 물은 질문에 대한 답 (대화, 2026-10-16)
- 사용자: 서버 회신 1장 Q1, 5장 1번 (docs/hmi-server-reply-1.md, 2026-10-16 전달)
- 직접: React 조작 화면에서 프로그램 종료 → 확인 창 → 종료 화면, 종료 뒤 서버로 보낸 메시지 0개, 연결 닫힘 (브라우저, 메인 서버 흉내, 2026-10-17)
