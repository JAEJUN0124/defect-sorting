# 서버 쪽 작업을 서버 담당의 회신까지 멈춤

## 요약
- 사용자가 서버 쪽 작업은 서버 담당이 우리가 보낸 파일을 보고 회신할 때까지 멈추라고 했다.
- 이 말로 서버 담당에게 파일을 보냈다는 것을 알았다. 어떤 파일을 보냈는지는 확인하지 않았다.
- CURRENT에 차단 한 줄을 더하고, api-spec의 재개 지점에서 "사용자가 요청서를 서버 담당에게 전하고"를 빼 회신 대기로 바꿨다. hmi-web의 재개 지점(회신과 v1.0 다음 판을 받으면 HMI를 맞춤)은 그대로다.
