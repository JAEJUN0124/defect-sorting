# 장치 연결은 계속 보이고, 각도 칸은 팔로워암·도로 (D-008 수정, D-020 추가)

## 요약
- 사용자가 장치 연결 줄을 앞으로도 계속 보일 것이라며 "(개발용)" 문구를 없애라고 했다. D-008을 "개발 단계 전용"에서 "계속 보인다"로 고쳤다.
- 사용자가 각도 칸의 "리더암 각도"를 보이는 문구만 "팔로워암 각도"로 바꾸고 다른 것은 건드리지 말라고 했다. 서버의 각도가 어느 팔의 것인지(서버 담당 답: 리더암)와 읽는 코드는 그대로다.
- 서버가 그리퍼를 퍼센트로 보내자, 사용자가 퍼센트를 임의로 각도로 바꾸라고 했다. 두 화면 결정을 D-020으로 더했다.
- 바꾸기 전 D-008 본문:
  - D-008 장치 연결 상태 표시는 개발 단계 전용
  - 범위: HMI 화면
  - 결정: 장치 연결 상태(서버·컨베이어·로봇팔·리더암·카메라)는 개발 중에만 보이고 나중에 뺀다. `devMode` 설정으로 끈다.
  - 근거: 사용자 2026-10-06 · HISTORY/2026-10-12-hmi-decisions.md

## 근거
- 사용자: "장치 연결(개발용) 되어 있는것도 이거 이후에도 계속 나타낼꺼라 (개발용) 텍스트 없애줘. 그리고 바로 배포까지" (대화, 2026-10-17)
- 사용자: "우리 hmi 리더암 각도잖아? 이거 보이는 텍스트만 팔로워암으로 바꿔줘. 다른건 손 안대도 됨" (대화, 2026-10-17)
- 사용자: "그리고 각도는 퍼센트로 보내주는데 이걸 너가 임의로 각도로 변환해." (대화, 2026-10-17)
