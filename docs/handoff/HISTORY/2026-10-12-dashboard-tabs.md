# 탭 대시보드 시안 v1~v2 — 왼쪽 탭, 색 위계, 각진 모서리

## 요약
- 사용자 요청: HMI 기능이 많지 않으니 최대한 나눠 "있어 보이게" 할 것. 왼쪽에 탭을 두고 색 위계로 구역을 나누며, 둥근 모서리는 되도록 빼되 필요한 곳은 써도 된다. frontend-design으로 설계하고 anti-slop으로 검수한 뒤 다시 고친다. 기존 대시보드(`hmi-web-mockup/dashboard.html`)는 그대로 두고 다른 시안으로 만든다.
- 새 화면 `hmi-web-mockup/dashboard-tabs.html`(스타일 `css/dashboard-tabs.css`, 스크립트 `js/dashboard-tabs.js`, 문구 `js/i18n/ko.js`)을 만들었다. 기능은 늘리지 않고 같은 값을 영역별로 나눠 자세히 보인다: 공정 흐름 그림, 30·60·120분 추이, 신뢰도 분포, 서보 온도 추이, 경보 기록 거르기 등.
- 왼쪽 탭 8개를 세 묶음으로 나눴다: 운전(개요·생산·검사) · 설비(로봇팔·리더암·장치) · 기록(경보·시스템). 뒤에 운전 묶음에 조작 탭이 더해져 9개가 됐다(HISTORY/2026-10-12-dashboard-controls.md).
- 색 위계는 면의 밝기 4단계(테 → 화면 바탕 → 판 머리 → 판)로 만들고, 색상(빨강·노랑·초록)은 지금처럼 신호에만 쓴다. 구역을 색상으로 나누면 IEC 신호색과 섞이기 때문이다. 선택된 탭은 화면 바탕과 같은 색이라 그 화면과 이어 보인다.
- 모서리는 각지게 하고, 원은 표시등과 긴급정지 버섯머리(실제 물건이 둥근 것)만 남겼다.
- 탭 옆에 그 영역에서 가장 나쁜 상태를 글자로 붙인다(`경고`·`비상`·`끊김 n`, 경보 탭은 확인하지 않은 수). 다른 탭을 보고 있어도 이상을 놓치지 않게 하려는 것이다.
- 윗판(상태·긴급정지·계수기)과 아래 줄(화면 이동·테마, 장치 연결, 마지막 경보, 시각)은 어느 탭에서나 보인다. 장치 연결 표시는 첫 대시보드처럼 `devMode`와 상관없이 늘 보인다.
- anti-slop 기준(S1~S15) 위반은 v1부터 0건이었다. 장식·중복 7건(윗판과 같은 값을 되풀이하는 줄, 다른 곳이 이미 말하는 안내 문장, "이상 없음" 앞의 초록 등, 값 없는 "–" 줄 2종, 진하게 칠한 눌린 단추, 안내 글자만 있던 카메라 빈 화면)을 v2에서 고쳤다. 카메라 빈 화면에 둔 "조작 화면 열기" 단추는 뒤에 "카메라 연결" 단추로 바뀌었다.
- v1은 `docs/v1-snapshot/dashboard-tabs.v1.*`에 남겼고, 설계·검수·측정은 docs/simplicity-report.md 11.1~11.3장에 썼다.

## 시도했다가 버린 방법
- 화면 이동·다크 모드 단추를 탭 줄 아래에 둠 → 탭 줄이 화면 높이를 넘음 (직접 2026-10-12 · 미리보기 브라우저) → 아래 줄로 옮김
- 탭 묶음 이름을 늘 보임 → 1280×720에서 탭 줄이 넘침 (직접 2026-10-12 · 미리보기 브라우저) → 높이 820px 이하 화면에서는 묶음 이름을 숨기고 간격만 남김
- 스크린 리더용 표를 판 안에서 숨김 → 판에 기준 위치가 없어 숨긴 표가 문서 높이를 늘림 (직접 2026-10-12 · 미리보기 브라우저) → 판에 `position: relative`
- 숫자 칸 최소 폭을 넉넉히 둠 → 화면에 세로 스크롤 막대가 생기면 칸이 줄바꿈되며 판이 높아져 스크롤이 그대로 남음 (직접 2026-10-12 · 미리보기 브라우저) → 최소 폭 80px
- 다크에서 공정 흐름 칸을 판보다 한 단계 밝게(`#394249`) → 빨간 글자 대비 4.15:1 (직접 2026-10-12 · 측정 도구) → 칸을 판과 같은 `#30383E`로, 칸은 테두리·이름표로 나눔
- 눌린 범위·등급 단추를 진한 면으로 칠함 → 긴급정지 다음으로 튀는 단추가 하나 더 생김 (직접 2026-10-12 · anti-slop 검수) → 키 면 + 진한 테두리
- 미리보기 브라우저에서 같은 주소·해시로 이동해 고친 코드를 확인 → 페이지를 다시 읽지 않아 옛 스크립트가 그대로 돎 (직접 2026-10-12 · 미리보기 브라우저) → `location.reload()`로 다시 읽음
