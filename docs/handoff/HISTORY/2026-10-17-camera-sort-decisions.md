# 양품/불량품 선택과 카메라 화면 (D-018·D-019 추가)

## 요약
- 사용자가 서버 담당의 카메라 영상 안내를 붙이고, 로봇팔이 양품·불량품 중 무엇을 옮길지 작업자가 고르게 해서 고른 값을 서버에 보내라고 했다.
- 구현 전에 물은 세 가지에 사용자가 답했다(그때 브랜치는 `feature/cloudflare-hmi`). 작업 전에 main을 먼저 합치기, 카메라는 화면 하나에서 탑뷰·그리퍼 바꾸기(D-019), 옮길 부품은 정지 상태에서만 바꾸기(D-018).
- 구현 중 사용자가 "HMI가 왜 양품·불량품을 판단하느냐, 고른 값만 서버에 보내면 된다"고 바로잡았다. 그래서 HMI는 판정하지 않고 고른 값만 보내며, 그 값을 어떻게 쓸지는 서버·장비가 정한다(D-018). 이에 맞춰 자동 가동 중 상태 설명을 고른 값에 따라 바꾸던 것을 중립 문구로 되돌리고, 서버에 보낼 문서에서 공정 처리·처음 값 제안·서버 규칙 요구를 뺐다.
- 같은 대화에서 사용자는 가짜 서버(개발용)가 지금도 가짜 판정과 개수를 내는 것은 자기만 보는 화면이라 그대로 두어도 된다고 했다.

## 근거
- 사용자: "첨부한 문서랑 추가로  로봇팔이 양품 / 불량품 뭐 선택할지 유저가 고르게. 이걸 양품/ 불량품 서버에 뭐 선택된 상태인지 보내야함. 둘 다 구현. 특히 첨부된 문서쪽엔 카메라 관련도 있음." (대화, 2026-10-17)
- 사용자: 질문 답 "main에 먼저 합치기", "한 화면 + 바꾸기", "정지 상태에서만" (대화, 2026-10-17)
- 사용자: "양품 가품 판단을 니가 왜 해 걍 니는 뭐가 선택됬는지만 서버에 보내면 돼" (대화, 2026-10-17)
- 사용자: "ㄴㄴ 가짜 서버는 차피 안보이잖아 나만 보는거고. 그럼 됬음." (대화, 2026-10-17)
