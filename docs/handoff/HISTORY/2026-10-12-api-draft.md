## 요약
- docs/API.md에 HMI가 서버에 기대하는 명령(HTTP), 실시간 메시지(WebSocket), 상태 모델, 이벤트 코드를 정리했다. 서버는 다른 팀원 담당이라 HMI 쪽에서 초안을 썼다.
