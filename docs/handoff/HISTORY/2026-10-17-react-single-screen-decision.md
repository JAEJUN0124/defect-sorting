# 조작 화면 하나만 React로, 대시보드는 없앰 (D-016 추가, D-012·D-013 폐기)

## 요약
- 사용자가 대시보드는 없애고 기본 조작 화면을 React로 똑같이 작동하게 바꾼 뒤, 서버에서 다 돌아가게 하자고 했다. 실제 카메라를 연결할 것이라 카메라 연결 때 나오던 가짜 영상도 빼라고 했다.
- 그 전에 대시보드를 빼면 잃는 기능(분당 판정 그래프, 최근 판정 목록, 경보 목록, 서보 온도·전압 표, 공정 흐름, 카메라 두 대 동시 보기)과 D-012·D-013을 고쳐야 한다는 점을 알렸다.
- 파일 삭제가 자동 권한 검사에 막혀 다시 물었을 때, 사용자는 대시보드 두 개와 React 전 조작 화면 파일을 "모두 지우기"로 골랐다.
- DECISIONS에 D-016을 추가하고, 대시보드가 없어져 대상이 사라진 D-012·D-013을 폐기했다. 폐기한 본문은 아래에 옮겨 적는다.
- D-008(장치 연결 표시는 개발 단계 전용)은 React 조작 화면에 그대로 적용된다.

## 폐기한 결정
- D-012 대시보드의 장치 연결 표시는 늘 보인다
  - 범위: 대시보드 화면(`hmi-web-mockup/dashboard.html`)
  - 결정: 대시보드의 장치 연결 상태(서버·컨베이어·로봇팔·리더암·카메라) 표시는 개발 단계가 끝나도 빼지 않고 늘 보인다. 대시보드에 한한 D-008의 예외다.
  - 근거: 사용자 2026-10-12 · HISTORY/2026-10-12-dashboard-device-display.md
- D-013 세 화면은 각각 혼자 쓰는 화면이다
  - 범위: 조작 화면(`hmi-web-mockup/index.html`)·첫 대시보드(`hmi-web-mockup/dashboard.html`)·탭 대시보드(`hmi-web-mockup/dashboard-tabs.html`)
  - 결정: 세 화면은 서로 기대지 않고 하나만 띄워도 라인을 다룰 수 있어야 한다. 그래서 두 대시보드도 조작 화면의 조작(F-01~F-06)을 모두 갖춘다. 다른 사람에게 보여 줄 사본도 화면마다 따로 만든다.
  - 근거: 사용자 2026-10-12 · HISTORY/2026-10-12-standalone-screens.md
- 폐기 이유: 대시보드 두 개를 없애 두 결정의 대상 화면이 없다 (D-016).

## 근거
- 사용자: "그러면 대시보드쪽은 날리고 기본 화면 있잖아? 그거 기준으로 리액트로 똑같이 작동하게 변경, 이후 마개조를 거쳐서 서버에서 걍 다 돌아가게 가능해? 말해줘" (대화, 2026-10-17)
- 사용자: 위 설명을 받은 뒤 "이젠 실제 카메라 연결할꺼라 그 카메라 연결 버튼 눌렀을때 가로 나오는건 날려도 될듯. 커밋하고 그대로 다음 브랜치에서 시작해" (대화, 2026-10-17)
- 사용자: 대시보드와 React 전 조작 화면 파일을 지울지 물은 질문에 "모두 지우기" (대화, 2026-10-17)
