# HMI 웹 화면 구현 — 라이트 v1~v3, 로그 창, 알림 점

## 요약
- 요구사항 F-01~F-06을 웹 화면으로 구현했다. Git 도입 전에 만든 작업이라 첫 커밋 15b267e로 main에 들어갔다.
- 화면: 왼쪽 조작반(상태 → 긴급정지 → 시작/정지 → 원점 잡기 → 운전 모드 → 프로그램 종료), 오른쪽 카메라 영상·생산 통계, 맨 아래 줄 로그 버튼.
- 실제 서버가 없어 브라우저 안 가짜 서버(`hmi-web-mockup/js/mock-server.js`)가 docs/API.md대로 응답하고, 카메라도 가짜 영상(`js/camera-sim.js`)을 그린다.
- 디자인: frontend-design으로 만들었다(색은 IEC 60073 신호 의미로만, 긴급정지는 노란 판 위 빨간 버튼). anti-slop 검수로 v2에서 그림자 3종 제거, 강조 버튼 3→2, 장식 아이콘 삭제, 모서리 10→8px, 반투명 버튼 불투명화.
- v3(사용자 요청): 로그 영역을 지우고 카메라를 그 자리까지 키웠다(1440×900에서 448→692px). 로그는 오른쪽 맨 아래 버튼으로 여는 비모달 창에서만 본다. 창은 보기 영역 위에만 떠서, 열려 있어도 조작반의 긴급정지를 누를 수 있다.
- 알림 점(사용자 승인): 창이 닫혀 있는 동안 경고·비상 기록이 생기면 로그 아이콘에 빨간 점을 켠다. 불량 검출은 정상 공정에서 늘 생겨 제외했다.
- 일반 정지(비긴급)는 요구사항에 없어 시작 키가 가동 중 "정지"로 바뀌는 토글로 가정했다. 모드 전환을 정지 상태에서만 허용하려면 긴급정지 말고도 멈출 방법이 필요해서다. 사용자 확정은 아직 없다.
