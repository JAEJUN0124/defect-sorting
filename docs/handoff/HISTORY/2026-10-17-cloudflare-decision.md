# 장비망 밖에서는 Cloudflare로 HMI를 연다 (D-017 추가)

## 요약
- 사용자가 장비망 밖에서도 HMI를 열 수 있게 하자고 했다. 작은 서버를 따로 두는 대신 사용자가 이미 산 도메인 하나로 처리하기로 했고, 공개망이 필요하며 Cloudflare를 쓴다고 했다. 이 화면은 따로 배포할 것이 아니라 장비망 밖에서 여는 것이 목적이라고 했다.
- 그래서 화면 파일은 Cloudflare Worker가 내주고, 서버(`http://10.108.108.98:5080`)로는 Cloudflare Tunnel로 `/ws/hmi`만 넘기며, 앞에 Cloudflare Access(허락한 이메일)를 두는 구조로 정했다. 서버 코드는 바꾸지 않는다.
- 메인 서버에서 화면을 띄우는 계획(서버 답장 0.1의 `wwwroot/`, 사용자 2026-10-17 "hmi를 메인서버에 올려서 작업하게")은 쓰지 않기로 바뀌었다. 묶음 도구는 장비망 안에서 인터넷 없이 띄울 때를 위해 남긴다.
- 사용자는 "따로 뿌릴 것은 아니라 괜찮다"고 했지만, Worker가 서비스 토큰을 들고 있어 화면 주소 앞의 Access가 꼭 필요하다고 권했고 사용자가 설정했다.
- 같은 날 서버 담당이 영상을 HTTP로 내준다고 안내해, Worker가 영상 경로도 넘기도록 넓혔다 (D-017 본문의 "서버가 HTTP로 내주는 영상", HISTORY/2026-10-17-camera-sort-target.md).

## 근거
- 사용자: "그러면 내가 서버 작은거라도 내주는게 좋아, 아니면 니가 더 마개조 해서 도메인 하나로 그냥 처리 가능하게 할수 있어?" (대화, 2026-10-17)
- 사용자: "그러면 서버는 스킵하고 걍 도메인 내꺼 하나에 올려서 서버가 이걸 보게 할껀데 그걸 위해 걍 다 해결 가능함?" (대화, 2026-10-17)
- 사용자: "공개망 필요하고 클플이야. 어짜피 뭐 이거 따로 어디에 뿌릴껀 아니라 그런건 ㄱㅊ을듯. 장비망 밖에서 여는게 목적." (대화, 2026-10-17)
- 사용자: "이미 내가 이름 정해서 구매한 도메인이 있음" (대화, 2026-10-17)
