# HMI 다크 테마와 "다크 모드" 버튼

## 요약
- 라이트와 배치·크기·글자는 같고 색 토큰만 다른 다크 테마를 추가했다(제어함 안트라사이트 회색 판 콘셉트). 긴급정지 색(노란 판·빨간 버튼)은 ISO 13850 고정색이라 두 테마가 같고, 시작 키는 다크에서 흰색이다(IEC 60204-1 시작 버튼 권장색).
- 만들기 전 대비 계산으로 2건을 고쳤다. 노란 판 위 글자는 다크 글자색을 쓰면 1.45:1이 되어 테마와 무관하게 검정으로 고정했고, 비상 빨강 글자는 `#FF6166`이 로그 창 바탕에서 4.5:1 미만이라 `#FF7D82`로 올렸다.
- anti-slop 검수: 슬롭 패턴 0건, 구조 문제 1건(다크에서 카메라 화면 틀이 사라짐). 1px 틀 `#737C84`(바탕과 3.33:1)를 넣고 가짜 영상 바탕을 화면색 토큰으로 통일했다.
- HIG 다크 모드의 7:1 목표에 맞춰 다크 보조 글자를 `#9EA7AF` → `#B3BBC2`로 올렸다. 라이트는 확정된 화면이라 그대로 뒀다.
- 테마: 처음에는 PC 설정(prefers-color-scheme)을 따르고 오른쪽 맨 아래 "다크 모드" 버튼으로 바꾼다. 고른 값은 브라우저 localStorage `hmi.theme`에 저장한다. 적용 순서는 주소 `?theme=` → 버튼으로 고른 값 → `js/config.js`의 `theme`.

## 시도했다가 버린 방법
- 테마를 바꿀 때 키 색 전환 효과를 requestAnimationFrame 두 번 뒤에 다시 켜기 → 화면이 숨겨진 탭에서는 rAF가 돌지 않아 전환 효과가 꺼진 채 남음 (직접 2026-10-07) → 강제 리플로(`offsetHeight`) 뒤 바로 다시 켬
- 화면 버튼 없이 PC 설정만 따르기 (HIG 권장) → 사용자가 버튼을 요구 (사용자 2026-10-07) → "다크 모드" 버튼 추가
